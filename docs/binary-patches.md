# 窗口与保活配方参考

本目录是独立参考，不是 ACP 安装步骤；本包不含 agy.exe，也不自动修改二进制或开启保活。首次开发可完全不碰这些配方。

- antigravity-context-window.json：工作区当前1.0.9配方，针对 Windows x64 AGY 1.5.9。把 ContextWindow 接到保存选择的getter；不能只改Pi目录里的512K登记就断言原生预算已更新。
- antigravity-keepalive.json：工作区1.0.1配方，针对 AGY 1.5.7，开启客户端原有最大6针、270秒调度。它不证明服务端缓存续期成功，不能套到1.5.9。
- 两份是不同版本的快照，不能顺序叠加到同一个任意exe。文件SHA、offset和before/after必须与目标构建对应；源码清单标明这些配方来自已有未提交工作区，不冒充本任务已审定发布版本。
- 修改exe会使原数字签名失效；Windows正在运行的映像可仍引用旧字节，磁盘替换成功不等于所有存活进程已采用。已有同盘映像换位的运维经验，不把本包交接扩张成重启别人的会话授权。
- target.path已替换为占位符，防止沿用原作者机器路径。将来需要维护配方时先取得本机目标身份、离线精确验证正逆变化；本文不授权在线缓存实验或全局安装。

[保活失败复盘](keepalive-failure.md)是本包对实际效果的结论。不要照旧AGY工具包“开启保活”一句话就把失败影子方案当成可用功能。
